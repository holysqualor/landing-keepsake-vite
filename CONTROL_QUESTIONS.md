# Відповіді на контрольні запитання

1. `dependencies` потрібні під час виконання застосунку, `devDependencies` — для розробки й збірки. Vite, Sass і лінтери не потрібні браузеру.
2. `package-lock.json` фіксує дерево й версії залежностей; його комітять для відтворюваних збірок. `node_modules` генерується автоматично. `npm ci` встановлює строго за lock-файлом і очищає попередні модулі; `npm install` може оновлювати lock-файл.
3. `^7.1.7` дозволяє сумісні мінорні/патч-версії до 8.0.0; `~7.1.7` — патч-версії до 7.2.0.
4. Препроцесор Sass перетворює SCSS у CSS до використання; постпроцесор Autoprefixer змінює готовий CSS.
5. `include` вставляє файл, `extends` успадковує базовий макет. `block` визначає область заміни, `append` додає після, `prepend` — перед її вмістом.
6. Міксин отримує вкладений вміст через `block`, атрибути — `&attributes(attributes)`. У проєкті `section-heading` використовує `block`, `btn` — атрибути.
7. `//` у Pug створює HTML-коментар, `//-` лишається лише в шаблоні. Умовний клас: `class={'site-nav__link--active': i===0}`.
8. Sass `@import` застарів через глобальний простір імен та повторні завантаження. `@use` підключає модуль, `@forward` реекспортує його; partials — файли з `_`.
9. `mq(md)` генерує лише `min-width`: базові стилі — для мобільних. Map зберігає єдині іменовані брейкпоінти.
10. `$var` існує під час компіляції Sass; `--var` доступна браузеру й може змінюватися в runtime. Токени задаються Sass map і експортуються в CSS custom properties.
11. Надмірна вкладеність збільшує специфічність і складність. `&__` та `&--` формують БЕМ-елементи та модифікатори.
12. PostCSS — платформа трансформацій CSS; Vite автоматично читає `postcss.config.js`. Autoprefixer використовує цілі Browserslist.
13. Vite компілює SCSS за наявності Sass, обробляє CSS, мініфікує збірку; cssnano не потрібен. Autoprefixer забезпечує повноцінні префікси для цільових браузерів.
14. JPEG — фото з втратами; PNG — без втрат і прозорість; WebP/AVIF — сучасне ефективне стиснення; SVG — вектор. AVIF стоїть першим, щоб сумісні браузери обрали його, інакше WebP або JPEG.
15. `sizes` описує розмір зображення в макеті, `srcset` — доступні ресурси; браузер враховує щільність пікселів. `width`/`height` резервують пропорції та зменшують CLS.
16. `loading="lazy"` — для контенту нижче першого екрана; `fetchpriority="high"` — для критичного hero-зображення, якщо воно є.
17. Prettier форматує код, Stylelint аналізує стиль і правила CSS/SCSS. Стандартний regex замінено для підтримки `__` і `--` у БЕМ.
18. Git hooks виконують перевірки на локальних подіях. Husky керує хуками, lint-staged перевіряє лише staged-файли. CI потрібен, бо локальні хуки можна обійти.
19. `base: '/landing-keepsake-vite/'` забезпечує правильні URL ресурсів на GitHub Pages у підкаталозі репозиторію.
